05

Questions & answers

The short version of everything you might wonder about.

How do I translate an EPUB or PDF to Hindi?

Open your EPUB or text-based PDF in Deep Translate, select the source language and Hindi as the target, then start. Alternatively, open the file here, enable Chrome’s Hindi translation and run chapter verification.

Is Novelxplin free to use?

Yes. You can open, review and export books without an account or subscription. Third-party translation services have their own availability and rate limits, which may pause or slow a translation.

Which layout should I use?

Studio (this page) for desktop with the shared library and tools. Classic if you want the original, fully local page. Xplin Go on a phone with Chrome translate. Deep Translate when you don’t have Chrome’s translator at all.

Does my book stay on my device?

File parsing, editing and export happen in your browser. Chrome translation and Deep Translate send text to their translation providers. The shared library syncs verified chapters to Firebase; turn it off in the workspace before starting if you don’t want to share.

Does “verified” mean the translation is accurate?

No. Verification checks for a script or text change to detect untranslated content. It does not guarantee meaning, grammar or literary accuracy — review the output, especially for important documents.

Can I continue a translation later?

Yes. Progress is stored in this browser. Reopen the same file on the same device to resume. Keep a JSON backup for safekeeping: clearing site data or private browsing can remove saved sessions.

Can I translate on my phone or offline?

Deep Translate works on mobile without Chrome’s page translator. Xplin Go is a phone-first browser-translation layout. The installed app shell works offline, but new translations need an internet connection.

Which file types are supported?

EPUB, text-based PDF, DOCX and TXT. Scanned PDFs (images) need OCR elsewhere first. Chapter headings like “Chapter 12”, “Part II”, “अध्याय 5” are detected automatically.
